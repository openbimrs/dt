# openbim-dt plan

Updated: 2026-08-25

## Current baseline

- ISO 23387 edition 2 namespace constant.
- Named pre-release placeholder namespace for future diagnostics.
- No data model, codec, semantic validation, governance workflow, or mapping.

## Next milestones

1. Model ISO 23387 concepts without embedding restricted standards text.
2. Add a lossless XML representation with explicit unknown-content retention.
3. Add structured validation diagnostics separately from parsing.
4. Integrate ISO 23386 governance concepts behind explicit contracts.
5. Add LOIN and dictionary consumers only after the lower-level contracts are
   published and independently tested.

Every milestone requires public or original redistributable fixtures, positive
and negative tests, and an updated capability table.
